User Guide

A step-by-step guide for collaborators using raw featureCounts data to run differential expression, PCA, volcano plots, heatmaps, overlap analyses and GSEA directly in a web browser.

Quick start

1. Load data

Upload one raw featureCounts table per biological sample/library, then check sample names and conditions.

2. Define the comparison

Put the reference/control samples in Group A and the tested condition in Group B.

3. Run & explore

Run differential expression, then inspect PCA, volcano plots, DEG tables and heatmaps.

4. Enrichment & export

Use GSEA or Custom GSEA, then download the tables and matrices you need.

Direction rule: every differential-expression result is Group B vs Group A. Positive log2FC means higher expression in Group B; negative log2FC means higher expression in Group A.

1 · Upload

Start from raw featureCounts tables. Do not upload normalized expression.

UseDo not use
Raw non-negative integer counts
One biological sample/library per file
Consistent gene IDs across files		TPM, FPKM, CPM
Log-transformed expression
R1/R2 reads treated as separate replicates

Accepted files

.tabular, .txt, .tsv and .csv.

Gene annotation

For Human or Mouse, the app attempts to map Ensembl IDs to gene symbols and names. Symbol-dependent features require successful annotation.

Paired-end data: R1 and R2 are reads from the same library, not biological replicates.

2 · Samples

Check metadata before running any analysis.

Use

Untick a sample to exclude it from analysis, for example a poor-quality sample.

Condition

Use clear biological labels such as Control, Treated, Sensitive or Resistant.

Sample

Sample names must be unique and should be easy to recognize later.

Batch / experiment

Record genuine technical batches, but do not assume every experiment label must be corrected.

Batch correction: enable it only when batch is a real nuisance factor and is not completely confounded with condition.

3 · Differential expression

BulkRNA Explorer runs pairwise differential expression with PyDESeq2.

Choose Group A and Group B

Group A is the reference/control. Group B is the condition you want to test.

Example: Group A = Sensitive and Group B = CDDP_R → positive log2FC means higher in CDDP_R; negative log2FC means higher in Sensitive.

Replicates

The app requires at least two samples per group. Proper biological replication is strongly recommended.

PCA

Use PCA to see whether replicates cluster together, whether conditions separate, and whether an unexpected sample or batch dominates the dataset. PCA is exploratory; do not remove a sample only because it looks different without a biological or technical reason.

Volcano + DEG table

Set an adjusted p-value and absolute log2FC threshold. A common exploratory starting point is padj ≤ 0.05 and |log2FC| ≥ 1, but these are not universal rules.

Top-DEG heatmap

Choose UP in Group B, UP in Group A, both directions top N total, or top N per group. Z-scoring emphasizes relative patterns within each gene.

Common / Venn

Save two or three pairwise comparisons in the same session, then compare UP, DOWN or all significant DEGs. Select any Venn region to inspect and download its genes.

5 · GSEA

Standard GSEA ranks all annotated genes by the PyDESeq2 Wald statistic.

Collections include Hallmark, GO Biological Process, GO Molecular Function, GO Cellular Component, Reactome and KEGG.

ResultInterpretation
Positive NESEnrichment toward Group B
Negative NESEnrichment toward Group A
Lower FDR q-valueStronger pathway-level evidence after multiple-testing correction
GSEA is not a DEG-only analysis. It uses the ranked list of all annotated genes, not only genes that pass a significance cutoff.

6 · Custom GSEA

Test only pathways you choose, or define your own gene sets.

A. Select specific pathways

Choose a collection, search by keyword (for example senesc, apoptosis or DNA repair), select only the relevant terms, review matched gene counts and run the selected-pathway GSEA.

B. My custom gene sets

Paste gene symbols or Ensembl IDs, or upload TXT/CSV/TSV files. Multiple sets can be uploaded using two columns such as:

pathway,gene
Senescence,CDKN1A
Senescence,CDKN2A
Stemness,SOX2
Stemness,NANOG

The app shows matched and unmatched genes before running. Very small matched gene sets should be interpreted cautiously.

7 · Download

Download important results before ending the session.

  • Normalized counts
  • VST expression
  • Metadata used
  • Annotated differential-expression results
  • Gene annotation when available
  • ZIP archive with the main tables
Session-based: analyses are stored in the current Streamlit session. Do not assume a project will still be available after the session ends.

Troubleshooting / FAQ

The app does not find my genes

Check whether you entered gene symbols rather than aliases or uncommon identifiers. Symbol-based heatmaps expect gene symbols.

I get no significant DEGs

Possible reasons include small biological effect, high variability, low sample number, stringent thresholds, poor data quality or incorrect grouping. Check PCA and sample labels before changing thresholds.

GSEA returns no pathways

Check annotation, internet access to the library service, matched gene counts and minimum gene-set size.

Should I use batch correction?

Only when batch is a genuine nuisance variable and is not completely confounded with the biological condition.

Can I compare one sample vs one sample?

No. The app requires at least two samples per group, and proper biological replication is strongly recommended.

Can I use TPM or FPKM?

No. Differential expression requires raw integer counts.

Why are positive/negative directions opposite to what I expected?

Check Group A and Group B. The app always reports Group B vs Group A.

Does the app save my project permanently?

No. Download important outputs before the current Streamlit session ends.

Data privacy

BulkRNA Explorer does not intentionally create a database of uploaded counts. However, when hosted on a third-party cloud platform, uploaded research data are processed on that provider's servers.

For unpublished, confidential, patient-derived or otherwise sensitive datasets, confirm that cloud processing is compatible with your institutional data policy before uploading.

Scope & limitations

BulkRNA Explorer is intended to make common exploratory bulk RNA-seq analyses accessible to non-coding users. It does not replace experimental-design review, sequencing QC, biological replication, expert interpretation or validation of publication-critical findings.

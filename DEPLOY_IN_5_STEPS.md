# Deploy in 5 steps

1. Create an empty GitHub repository called **BulkRNAExplorer**.
2. Upload everything in this folder to GitHub.
3. Open **share.streamlit.io** and log in with GitHub.
4. Create app → choose `BulkRNAExplorer` → file `streamlit_app.py` → Python **3.12**.
5. Click **Deploy** and share the resulting `*.streamlit.app` link.

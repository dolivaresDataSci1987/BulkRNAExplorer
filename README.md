# BulkRNA Explorer — Documentation

This branch contains the collaborator-facing documentation for **BulkRNA Explorer**.

## Start here

👉 **[Open the full user guide](USER_GUIDE.md)**

The guide covers:

- uploading raw featureCounts tables
- checking samples and metadata
- differential expression with Group A / Group B
- PCA, volcano plots and DEG tables
- top-DEG heatmaps
- custom gene heatmaps
- Common / Venn analyses
- standard GSEA
- Custom GSEA with selected pathways or user-defined gene sets
- downloads
- troubleshooting, FAQ and data-privacy notes

## Web version

A standalone static website is also included as `index.html`. It is intentionally kept on this separate documentation branch so edits to the manual do **not** redeploy or modify the production Streamlit application.

## Intended audience

The documentation is written for collaborators who may have little or no command-line or bioinformatics experience. It focuses on what to click, how to interpret Group A vs Group B, and common mistakes to avoid.
